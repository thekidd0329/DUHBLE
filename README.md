# DUHBLE

**Dynamic Unification of Homeostatic and Brain-Like Engrams**

DUHBLE is the working language/runtime identity for a developmental, stateful computing project centered on a simple principle:

> Dormant is not gone.

The project explores whether inactive computational state can remain structurally present, retain history and relationships, survive consolidation, and later become relevant again without being treated as erased or equivalent to zero.

## Source files

DUHBLE source files use the `.duh` extension.

Examples:

- `app.duh`
- `runtime.duh`
- `memory.duh`

## Current status

This repository begins at a frozen research checkpoint. The present goal is to preserve the concept and its history without publishing implementation details or extending the experimental architecture from this checkpoint.

## Core idea

DUHBLE is not defined by a claim about what the system is. It is defined by a design question:

**What happens when inactivity and absence are no longer treated as the same computational condition?**

See `docs/CONCEPT.md` and `docs/FREEZE.md`.
